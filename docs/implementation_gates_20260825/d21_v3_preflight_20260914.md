- 方案3：逐成员日复核缺失来源，保存行级原因和行业覆盖。未取得可靠修复来源，所以没有将缺失行业或收益填零、前后填充或猜测补全。
- 方案4：实现小行业基准向市场LOO基准收缩的预检候选。同日有效同行n>=5保留行业LOO；n<5使用w=n/5，基准=w×行业LOO+(1-w)×市场LOO；n=0仅用市场LOO。目标股自身从两个基准中排除，未知行业仍缺失。
- 方案5：实现一个有限的短窗口候选，非窗口扫描。低波动20期/至少18个；残差动量60期跳过10期/至少45个；趋势效率20期跳过2期/至少17个。分别对应约一月风险、约三月动量跳过两周和较近趋势；仅为工程候选，没有声称其Alpha有效。

上述四种比较（原方案、仅收缩、仅短窗口、两者结合）在运行前固化进代码。未按收益选择，也未在看到覆盖结果后继续缩窗。
缩短窗口改变慢速信号含义；收缩残差也不再是严格纯行业残差，若后续采用必须单独冻结并验证市场暴露。

## 数据边界和复现

输入仅为v2 `development_features_slow.parquet`的date/code/industry_code/r_1d/epsilon/valid_slow_signal白名单列，以及`split_plan.json`。不打开标签、PnL、sealed目录或Holdout。
r_1d是当时历史日收益，作为特征原料，不是未来收益标签。
历史仍限当日指数成员，非成员日保持NaN，没有实施方案2的入选前预热。
使用原始五折验证日期：1535个日期、460500个成员日。此口径不同于剔除边界后的Stage4成交路径日期，因此原方案77.7153%与Stage4的77.7176%略有差异。
重算原始残差与v2列数值一致；原始三信号有效掩码逐行完全一致。
