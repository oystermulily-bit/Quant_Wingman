## 1. 产品流程与白名单含义

沿用：最终公式／模型在点时沪深300全池生成当期评分，完整展示300只；用户勾选并保存版本化白名单，再进入配置层。缺分股票保留展示。排名不使用个股IC，也不截为Top20或Top30。

用户已明确：形成有效配置建议时，每只所选股票都必须得到严格大于0的推荐目标权重；未选股票不得新增买入。不能因为低分、相关性高或交易费高就把某只所选股票的推荐目标设为0，也不能擅自移出白名单。

建议区间以仓位权重为单位，整体不得出现负数。推荐目标、区间下限、区间上限分别记录，满足“0≤下限≤推荐目标≤上限”；推荐目标必须>0。用户已确认区间下限允许=0，但不要求强制设为0。工程版生成方法见上述实施记录，不把它冒充收益置信区间，也不能把所有股票区间上限同时取满而绕开组合约束。

实现前须确定有实际意义的最小正权重或最小交易金额，不能用接近0的极小数敷衍“必须配置”。资金、费用、交易单位、行业与风险约束必须支持所选股票同时持有；不可行时明确报告冲突，不生成把部分所选股票置零的成功方案。

白名单版本绑定用户所见的评分日期、公式／模型版本与数据快照。跨日期更新评分时，系统要求确认名单沿用，并记录新快照引用，不把旧分数当成新分数。

## 2. 配置目标

建议首版采用“带收益不确定性和交易成本的单周期组合优化”，求解股票权重与现金比例：

```text
目标效用 = 组合预期超额收益（相对同周期现金）
         − 收益估计不确定性扣减
         − 组合波动与相关性风险惩罚
         − 本次买卖的手续费、税费及滑点
```

股票排名得分与目标效用不是同一个量：排名得分属于单只股票，目标效用属于整套权重方案。二者关系是“单股排名得分→校准后的预期收益及误差→结合全部股票权重、风险和费用计算组合效用”。目标效用不用于替换沪深300全池的股票排名。

得分不直接转百分比。高分但波动大、与已有股票高度相关、交易太贵的所选股票，可以少配，但有效建议中的推荐目标仍须>0。收益证据不足时报告无法形成有效建议；在非空白名单下，不能用“全部现金、所选全部为0”作为满足用户选择的成功方案。未成交或未采纳时实际账户仍可能是现金，须与推荐目标分开显示。

首版以协方差风险项和行业硬限额控制集中，不另加未经验证的行业预测分或独立集中度惩罚系数；额外换手偏好系数先设为0，避免把同一笔交易费重复扣两次。小额调仓通过第7节控制。此处是对旧组合合同中通用目标函数的具体化建议。

同时权衡收益、风险与交易成本可采用凸优化框架；预测本身仍须独立验证，优化器不会创造预测能力。方法依据：[Boyd等，Multi-Period Trading via Convex Optimization](https://stanford.edu/~boyd/papers/cvx_portfolio.html)。

## 3. 评分如何变为预期收益

建议增加独立的“收益校准层”：

1. 预测周期H沿用上游已冻结的模型／标签周期，不另挑回测最好看的周期；未通过对应研究验证时只允许离线实验。
2. 在每个外层评估窗开始前，使用此前内层样本外预测及已经到期的H周期收益校准分数。外层窗口内冻结校准器，不能拿正在评估的未来收益回调它。
3. 校准样本覆盖当时完整股票池，按日期等权；不只拿用户勾选股票拟合。拟用最近504个已成熟信号日，至少252日，不足时返回证据不足。
4. 首版使用预先定向后的全池分数百分位，拟合单调的线性收益映射。映射目标是与执行标签一致的H周期毛总收益减现金收益。若上游给出行业残差分数，仍需完成这一步，不能把残差收益直接冒充绝对盈利空间。
5. 收益均值的不确定性按时间块估计，不把同一天300只股票当300个独立日期。建议优化时使用“估计均值减1倍标准误”的保守收益；它是保守扣减规则，不宣称有固定覆盖率或保本效果。
6. 分数方向、映射与不确定性方法均在内层确定。校准关系在样本外无效或只剩市场漂移而无评分区分能力时，不进入收益优化路径。

拟合层和校准层输出的是估计值，页面同时给出估计误差、周期和来源。界面不把它展示成确定收益或上涨概率。

## 4. 风险与行业规则

沿用：普通A股模式仅做多，不融资；单股意向目标≤5%，申万一级行业目标合计≤30%；股票目标合计≤用户预算和有效市场预算的较小值。

新增用户约束：每只所选股票推荐目标>0。最小正权重确定后，必须先验证所有最低权重之和、各行业最低权重之和及最低买入费用均可被预算容纳。预算为0而白名单非空、或其他约束冲突时，返回不可行说明，不擅自放宽5%／30%上限或给所选股票零目标。

建议新增：

- 风险矩阵纳入白名单股票及所有当前持仓，考虑股票波动和共同涨跌，不能只看单股波动。
- 风险估计采用截至当时的历史总收益和Ledoit–Wolf收缩协方差。建议取最近504个交易日内、与H及执行价格口径一致的非重叠H周期收益，至少60个共同有效周期；缺失数据不随意填0。方法依据：[LedoitWolf官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.covariance.LedoitWolf.html)。
- 风险矩阵必须有限、对称、半正定；历史不足的股票不新增买入。旧仓风险数据缺失时保留旧仓事实并暂停收益驱动的新买，不能把旧仓从风险中删掉。
- 建议首版设置预测年化波动上限12%，年化口径沿用项目239交易日；优化使用H周期单位。12%是待审核的风险预算，不能限制真实最大回撤或保证实际波动不超限。
- 风险厌恶系数建议固定为3，均值、方差、费用均按H周期和账户净值比例计量；1和10只作已登记敏感性检查，不从外层成绩中挑冠军。
- 市场层、行业层只通过已冻结预算或约束进入配置，不再加一次市场／行业分数。没有通过验证的状态模块时，明确使用“固定预算模式”，不能假装已有择时或行业预测。
- 行业不明时仍统一归入UNKNOWN，共用30%上限；正式运行优先要求可核验的点时行业数据，不允许靠随意改行业名称绕开限额。

首版不强制相对沪深300行业权重完全中性。小白名单可能根本无法复制指数行业结构，不能因此偷偷买入未选股票。

本版是行业分散和相关性风险控制，不是真正的多空行业对冲。引入融券、期货或白名单外对冲工具，需要另版明确交易权限、保证金、基差和成本规则，本草案不启用。

## 5. 成本、滑点与流动性

沿用研究对照成本：买入0.076%、卖出0.126%，已经包含每边0.05%滑点。不得再次重复加这一笔滑点；这组数是项目冻结的参考假设，不是声称所有账户当前都按该费率收费。[原参考口径](frozen_design.md#7-成本与可交易性)

建议新增“账户方案成本”独立版本：

- 有账户资金、券商费率和规则版本时，按买卖方向计算佣金、最低佣金、税费、过户等费用；每个实际订单收费，不把零成交订单也收费。
- 滑点拆出独立字段，使用有历史依据的报价／成交模型或明确标识的参考情景。没有成交证据时不声称已校准市场冲击；至少披露基准和1.5倍成本压力结果。
- 沿用新开仓20日成交额中位数≥2000万元的门槛；另建议单次交易金额不超过截至信号日20日平均成交额的1%。1%是预交易容量上限，不代表开盘时一定能成交，执行窗口仍需独立检查。
- 无账户资金时，只输出比例和比例费用；不输出股数、最低佣金或容量检查通过的结论。
- 有账户资金时，按该证券适用的交易单位、可卖数量和价格精度生成股数，买入向下取整，余款留现金。不能统一假设所有板块的交易单位相同。取整后若某只所选股票预计持仓为0，须判定完整建仓方案未满足要求并报告原因，不能把连续正权重当成已经能执行。

H是预测与决策周期，不代表每到H日就必须全仓卖掉。优化计入本次计划交易成本，后续实际调仓在发生时记账；新建仓另展示一次完整买卖的往返成本敏感性，不能只用买入费声称已覆盖整个持有过程的成本。

连续权重优化先使用可求解的比例成本近似，再对股数取整、最低佣金和真实订单重算费用与约束。最低佣金、交易单位等会使问题不再是简单凸优化，首版不宣称获得离散订单的全局最优解。[固定交易费研究](https://web.stanford.edu/~boyd/papers/portfolio.html)

## 6. 权重、现金与旧仓

现金由收益机会、风险上限、白名单范围、费用和可交易性共同决定，不为了显示“满仓”强制投入全部资金。

现金只能使用满足全部所选股票正目标后剩余的可用资金。无法同时满足时标记无有效配置／约束不可行；停止新增、保留原仓或实际全现金属于失败后的账户处理，不等于已经完成所选股票的配置。

- 分别输出意向目标和考虑执行条件后的预计持仓／现金；两者不能混为一个数字。
- 为兼容现有接口，意向 `cash_weight`包含预留费用，满足目标股票+目标现金=1；另列扣费后的现金。预计成交结果满足预计股票+预计现金+本次费用=调仓前净值。
- 成本进入目标函数并从账户资金中扣除：前者决定交易值不值得做，后者是现金记账，不是收费两次。
- 当前持仓未知：只给条件目标和缺失说明，不生成增减仓或成交方案。全部现金不能代替“持仓未知”。
- 白名单外旧仓的意向目标为0，实际仓位仍按可卖数量逐步退出。不能卖出的部分持续占用现金之外的股票、行业和总风险空间。
- 执行情景求解时，把不能卖出的旧仓固定在账上，在剩余空间内重新分配可买部分，不能先假设旧仓卖掉再买满。
- 旧仓已经超限且不能卖出时，披露超限和原因；禁止进一步加重该超限。不能为获得可行解而删除旧仓、放宽白名单或把它写成现金。

即使使用优化器，也可能出现等权：若只选5只股票且它们都值得配到单股5%上限，结果仍是每只5%、现金75%。新算法允许不等权，不承诺每次结果都不等权。

## 7. 调仓与不交易规则

建议正常收益驱动调仓按模型H周期运行，信号在t日数据可用后保存，计划于t+1执行；研究报告所有相位，正式相位提前冻结。风控退出、成员调出和旧仓受阻后的重试另行每日检查，不反向改写原信号。

每次从当前真实持仓出发计算买卖，不默认从空仓建仓。生成建议、用户采纳、实际执行是不同事件；首版配置建议不自动下单。

建议不交易区：

1. 正常主动调仓中，单股权重变化绝对值小于0.5个百分点，先固定为不动，再在剩余股票中重解；强制退出和必要降险不受该阈值阻止。不能用此规则把当前零持仓的所选股票永久固定为零；其首次配置还须满足正目标、最小交易单位和费用检查。
2. 完整订单重计最低费用和滑点后，新方案的保守效用不高于“维持合法当前仓位”的效用，返回 `NO_TRADE`；需要退出的违规／调出持仓先进入强制处置，不能以省成本为由继续主动持有。
3. 微调固定、重解与舍入修复采用固定顺序和迭代上限。若不能获得满足硬条件的方案，暂停新增买入并报告失败，不反复换参数直到有交易。

`NO_TRADE`表示本次不执行交易，不表示允许发布所选股票零推荐目标。若原仓仍有某只所选股票为0，必须同时说明用户要求尚未满足；买入受阻时也分别保留正意向目标与真实零成交，不能声称已经全部配置完成。

t+1只更新成交条件、价格、可用资金和成本检查；原分数、预期收益和原意向目标保留。执行修正单独版本化。价格或成本恶化使原交易不再值得做时，可以少成交或取消，不能回填成t日没有信号。

## 8. 数据失败和求解失败的回退

既有文档存在两种通用回退顺序：组合合同包含风险平价／等权，产品待办还包含保留原仓。本次建议统一首版为以下顺序，须审核后再写入正式合同：

1. 数据、收益校准或模型验证不通过：暂停新增收益驱动配置；记录并保留实际持仓，风险退出按已知事实处理。不得自动改用等权并标记优化成功。
2. 数据有效但求解数值失败：固定数值容差后重试一次；仍失败则保留合法原仓，受限或违规仓进入明确的退出／受阻处理。
3. 若账户原本空仓且没有可发布方案，保持现金；若旧仓不能退出，只能报告残留旧仓，不能声称100%现金。
4. 风险平价和受约束等权保留为研究基准。以后若批准它们作实盘回退，必须单独验证、明确展示回退原因和方法，不能静默启用。

所有输入相同，输出应确定；固定求解器版本、容差、同分排序、重解顺序和随机种子。

## 9. 回测与上线验收

以下是针对“新配置器”的新增实验建议，不能改写D21或S2既有结论和旧门槛。

### 9.1 算法级回测

- 上游筛选／拟合、收益校准、风险估计和配置都纳入按时间滚动的样本外流程。采用项目的完整日期切分、5个外层折、Purge=20日、Embargo=5日，并逐样本验证标签已到期。
- 新配置器主实验允许使用当日完整300成员作为可配置名单，与同名单受约束等权比较。旧Top20参考仍单独保留，不改变其结果。
- 小白名单压力测试预注册5／10／20／50只及单行业集中场景，只用当时可见分数或固定种子形成名单；这些是研究情景，不修改产品全量300只入口，也不能挑最好情景宣传。
- 同日期、同股票池、同预算／硬限额、同成本和执行账本比较：受约束等权、波动倒数基准、新优化器。另报维持原仓和沪深300总收益参照，后两者不冒充风险完全匹配的策略对照。
- 拆分改进来源：收益选择、权重变化、持现／降风险、成本节省；披露风险匹配后的结果，不能把多承担风险带来的毛收益全称为算法能力。
- 费用按实际模拟成交扣除；停牌、涨跌停、延迟退出和退市损失均留在账本。未成交目标不产生虚构收益。

### 9.2 建议的新增接受门槛

唯一主比较：新优化器相对同名单受约束等权的扣费OOF全相位中位净Sharpe增量。建议全部满足：

1. 净Sharpe增量≥0.15，候选净Sharpe和扣费年化收益均>0。
2. 同日期配对移动块Bootstrap对Sharpe增量的95%区间下界>0；沿用20日时间块、2000次抽样，不按股票行抽样。
3. 至少3/5外层折、超过半数调仓相位方向一致；不得删除亏损相位。
4. 最大回撤不高于同约束等权；同时披露年化收益差，不能隐瞒通过大量持现降低了收益的代价。
5. 成本×0、×1、×1.5全披露；×1.5时候选净收益仍>0且相对等权的主指标增量不为负。
6. 剔除最强年份或最大贡献行业后，分别重新报告OOF主指标增量；若优势消失，标记集中依赖并不按“广泛稳定改善”通过。
7. 300成员、时点可用性、现金守恒、持仓状态机和硬约束测试全通过；冻结旧仓形成的不可避免超限必须独立披露，不能算作正常达标。

若样本不足、分母退化（如全现金导致Sharpe不可定义）或统计区间无法可靠估计，记为证据不足，不补造通过结果。未通过时保留简单基准并如实报告；每次试验都登记，不修改门槛后重解释同一批外层数据。反复挑回测赢家的过拟合风险见[Bailey等研究](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。

一次性Holdout沿用已有权限和冻结流程。本草案不申请读取；新配置器如何进入最终发布的Holdout验证，须在完整研究方案冻结时明确，不把当前人工白名单加入历史Holdout主结论。

### 9.3 每份建议与前向记录

每份建议发布前做资金、成本、行业、风险和执行条件复核，不每次重新搜索最赚钱参数。压力展示至少包括成本1.5倍、白名单内最大行业同步下跌10%、买入受阻和卖出受阻；这些是假设情景，不给它们赋予虚构概率，也不保证覆盖所有尾部风险。

用户今天选择的股票可以做历史风险复盘，但明确标记事后名单。真实白名单从保存之日起记录版本、建议、用户采纳、可执行性、模拟成交与后续表现；不能把今天的选择当成历史上当时已知的名单。

## 10. 用户最终看到的内容

- 组合：目标股票／现金、扣费后预计现金、H周期预期收益及误差、预测波动、行业权重、预计换手、费用分解和压力结果。
- 个股：分数与全池排名、校准收益及误差、行业、当前／推荐目标／预计执行后权重、建议权重区间（边界及生成方法冻结后）、计划买卖、金额／股数（资料完整时）、执行状态。
- 解释：为何少配、为何整份配置不可行或为何未成交，例如收益证据弱、相关性风险高、行业上限、费用不划算、持仓受阻、历史不足。有效方案的所选股票推荐目标不得为0；实际零持仓必须与推荐目标区分。不得仅凭相关性检查就宣称某股票“对冲了行业”。
- 审计：名单／快照／模型／校准器／风险／成本版本、方法、求解状态、回退原因、数据时间及建议失效条件。
