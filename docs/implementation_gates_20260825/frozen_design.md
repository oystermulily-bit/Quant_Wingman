## 2. 数据设计

### 2.1 唯一正式输入

- 正式研究范围：`2014-01-02`至冻结快照的Development结束日。
- 原始抓取清单可以继续保留`requested_start=2010-01-01`，但它只描述历史请求和供应商覆盖缺口，不定义训练样本范围。
- 基础池：`000300.SH` 每日点时成分；每日权重是成员主证据，成分区间交叉核对。
- 行业：申万一级，必须带有效区间和分类版本。
- 行情：未复权 OHLCV、成交额、PRECLOSE、涨跌停价、停牌/ST/XR/WD。
- 公司行动：分红、配股、股本变更及公告原字段，公告时间与生效时间分开。
- 原始响应先不可变保存；正式研究只读本地冻结快照，禁止训练中访问 MCP。

### 2.2 研究起点决策（2026-08-28已确认）

正式研究起点冻结为`2014-01-02`，即首个同时具备可审计OpenTR、日线和方向性交易状态的完整交易日。2010—2013只保留为来源覆盖审计，不参与任何模型指标。

### 2.3 时间语义

所有事件保存：`event_at`、`effective_at`、`known_at`、`available_at`、`fetched_at`、`built_at`。`known_at_source` 和 `available_at_source` 必须为 `NATIVE|DERIVED_POLICY|MISSING`。

推荐保守规则：

- 日线 `available_at = 交易日 21:00 Asia/Shanghai`，仅在供应商无原生时间时标 `DERIVED_POLICY_V1`；信号只能在此后生成。
- 指数调整公告 `known_at` 缺失时，不允许提前使用调整信息；成员只从 effective date 的每日权重生效。
- 公司行动 known_at 只取真实公告/披露字段，不得用实施日代替公告日。
- OpenTR/CloseTR 从冻结 raw 的 PRECLOSE 链和事件账本本地构建，并通过前缀和现金流测试。

### 2.4 成员退出/退市

- 调出沪深300生效日起停止新开仓、目标权重为 0；下一可卖开盘退出。
- 停牌/一字跌停导致无法退出时为 `UNIVERSE_EXIT_PENDING`，仓位、风险和 PnL 继续保留。
- 重新进入指数视为新成员区间，不抹去旧区间。
- 退市不删除样本。若直到退市都无法卖出且缺少可审计处置价格，推荐在退市生效日记剩余仓位 100% 损失，并单列敏感性分析。

## 3. 标签与执行

信号时点：t 日完整收盘数据在 `available_at` 后。  
计划执行：t+1 交易日开盘。  
标签：

```text
y_H(i,t) = log(OpenTR(i,t+H+1) / OpenTR(i,t+1)), H ∈ {1,3,5}
```

同时构造绝对、相对市场、相对行业三类标签。标签只存在于独立 `labels/` 层，特征模块不得导入它。所有 IC、PnL 和胜率使用同一 label id 和相同 t 索引，不再额外 shift。

## 5. 第一阶段参考信号和组合

在周期可行性门禁中不启动 RD-Agent。使用冻结的三个简单信号：

- `MOM_20 = log(Close_pt[t]/Close_pt[t-20])`
- `REV_5 = -log(Close_pt[t]/Close_pt[t-5])`
- `LOW_VOL_20 = -std(r_1[t-19:t])`

当日截面 1%/99% 截尾、平均秩百分位、三信号等权为 `SIMPLE_ENSEMBLE_V1`。参考组合在当日点时成分内取 Top 20，每只 5%，不可交易空缺保留现金且不临时补第21名。该参考组合用于研究周期，不是用户白名单产品。

## 6. 验证设计

- 同一天全部股票进入同一折。
- 推荐 5 个 expanding Walk-Forward OOF 验证折；Purge 20 个交易日，embargo 5 日。
- 配对移动块 Bootstrap：块长20日、2000次、种子20260812、95% CI。
- 3 日 vs 1 日、5 日 vs 1 日用 Holm 家族5%；阶段5公式家族用 BH-FDR `q=0.05`。
- 主指标：扣费后 OOF 全相位中位数净 Sharpe。
- GO 至少要求：相对1日净 Sharpe +0.15、扣费年化 +2pct、差值95% CI下界>0、多数相位/折方向一致、最大回撤不差于1日的1.2倍。
- 1/3/5 日使用同一快照、日期折、成本、执行规则和参考组合。

### Holdout 冲突处理（已确认）

最新命令写“最后10% Holdout”，既有第一期协议写“禁止机械10%，至少两个完整日历年且不少于480个交易日”。2013—2026 的10%约330日，不能同时满足两者。

已冻结为：从尾部取 `max(完整交易日数量的10%, 480个交易日)`，并要求至少覆盖两个日历年；按日期整体隔离。这是“至少10%”而不是“恰好10%”。

Holdout 在阶段7冻结前物理不可读；阶段8只运行一次，之后该区间永久降级为已查看测试段。

新开仓流动性门槛已冻结为：截至 t 日的20日成交额中位数不低于 2000 万元；执行日停牌、一字涨停不可买，一字跌停不可卖。

## 8. 组合设计

阶段6以后：白名单外和非当日成员的新仓权重为0；A股普通模式长仓；总权重≤1；允许100%现金；单股≤5%；单行业≤30%；考虑波动、相关性、当前持仓、换手和方向成本。

确定性回退冻结为：

```text
组合优化失败
→ 降低总风险预算
→ 合法信号股票风险平价
→ 合法信号股票等权
→ 全部现金
```

每次保存 fallback level/reason、原始与冲突约束、最终权重和现金。
