# 全5%目标、区间与参数解释修复

## 已复现的原因

使用截图的7只合成股票：SYNTHETIC_264、061、020、012、220、276、114（均带SYNTHETIC_前缀），绑定2013-06-17评分及原配置证据。

1. 用户早先保存的最低目标为5%，与单股上限相同，目标与区间被硬约束固定。后来降为1%，当前收益、风险、成本下仍全部触顶。
2. 最新保存输入为最低目标1%、预算100%、波动上限30%、风险厌恶0.71、当前空仓。目标股票合计35%，预测年化波动约4.665%；预算与波动上限均未触及。
3. 风险厌恶改为3或10仍触顶，原因是原风险惩罚尚不足以改变边界解；系数约17.26为第一只股票脱离上限的局部阈值。系数30下七股权重约2.833%至4.060%。这只是同输入敏感性复算，不是推荐最优参数。
4. 旧区间只取三组收益扰动下最优权重的极值，三组都触顶时全部退化为5%～5%。它没有表达允许偏离最优点多少。
5. 参数确实写入请求并重新求解。最低目标、波动上限、预算都属于约束；约束不生效或全部被锁定时，改变参数不保证改变权重。空仓时小额调仓阈值不冻结首次建仓，卖出费率也不产生本次费用。

## 修复后的规则

目标继续使用原收益、不确定性、协方差风险和成本效用，不为制造差异而打散相同权重，也未更改5%单股上限或收益证据。

区间定义为：其他股票维持推荐目标，仅调整该股票及现金，在原硬约束内，模型本期效用相对推荐方案下降不超过 `range_utility_tolerance_bps / 10000` 的连续可行权重范围。默认1基点即账户净值0.01%的模型效用容忍度，用户可设0至100基点；该设置只影响区间。它不代表收益概率、统计置信区间、最大回撤或成交保证。

区间遵守用户最低目标；用户允许下限为0不等于必须把每份区间设为0。最低目标与上限相同、调仓冻结或没有可调空间时如实显示“固定”，不制造虚假宽度。多股区间不能任意组合，组合调整需重新计算。

实现按交易费用分段，求解单变量线性与二次不等式；处理最低佣金在不交易处的费用跳变，不连接不满足效用或资金约束的区间。300股不需要额外进行600次完整组合求解。股数、流动性与可交易限制继续由独立执行模拟处理。

在截图的最后一组参数、默认1基点容忍度下：七股目标仍为5%，各股建议下限约3.018%至3.198%，上限5%。容忍度2基点时下限约1.062%至1.418%。预算改20%、波动上限改2.5%、风险厌恶改30、买入费用提高分别能够影响目标，测试逐项验证。
