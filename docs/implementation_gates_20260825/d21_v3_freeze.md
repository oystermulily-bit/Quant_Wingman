## 两个池严格分离

- 交易、截尾、排名、Top20/Top40、标签和OOF门禁：仅当日点时沪深300成员。
- 残差参考池：当日沪深300，加当日中证500中申万一级电子、计算机、通信成员，按日期和代码去重。新增股票不因参考池身份获得交易资格。
- 行业LOO和市场LOO均在参考池计算并排除目标自身。行业未知股票不参与行业均值，其有限收益可参与市场均值，沿用已预检定义。
- 先计算参考截面，再仅保留沪深300目标成员日，最后按完整研究日历滚动。股票非沪深300成员日的自身残差仍缺失，即使当时在科技参考池也不能预热其目标信号。
- 原沪深300成员中的新增/退出遵循原点时成员规则，不按今天的名单回填历史。

## 收缩及长窗口

令n为除目标自身外行业有效同行数。n≥5使用行业LOO；0<n<5使用 `(n/5)*行业LOO+(1-n/5)*市场LOO`；n=0明确使用市场LOO。目标行业或目标收益缺失则残差缺失；所需参考无法计算也缺失。不把缺失收益填0。

目标残差 = 目标当日log总回报 − 上述参考。

- `IDIO_LOW_VOL_60`：最近60日残差负总体标准差，至少54个有效值。
- `RES_MOM_120_20`：跳过最近20日，较早100日残差和乘100/有效数，至少90个有效值。
- `RES_TREND_EFF_60_5`：跳过最近5日，较早55日残差和除以绝对残差和加1e-12，至少50个有效值。
- 仅沪深300目标截面1%/99%截尾、平均秩百分位；三信号全部有效才等权平均。缺一不可重平均。
