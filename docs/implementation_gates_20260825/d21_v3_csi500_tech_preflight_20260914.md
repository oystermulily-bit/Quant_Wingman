# 中证500科技股扩池预检：2026-09-14

结论：已完成独立候选池扩展和 Development 覆盖率检验，四个预设方案均未达到95%。不是收益不合格的新证据，也不是正式 GO；收益门禁未运行。

## 范围与方法

- 原候选池为逐日沪深300全体成员；新增“当日中证500科技股减当日沪深300”。没有把今天的股票清单回填历史。
- 科技定义沿用数据项目 `config.hs300_tech.toml`：申万一级电子、计算机、通信，不含传媒。没有采用该项目另一个包含传媒的默认配置。
- 采用 AmazingData 历史指数和行业的 INDATE/OUTDATE 有效区间；逐日中证500成员数均验证为500。区间含起止日，沿用现有适配器约定。有效区间不等于已独立核验公告可得时点，正式数据门禁仍须审查这一点。
- 研究日期2014-01-02至2024-08-23；保持原5折验证日期，共1,535个OOF日期、565,602个扩池成员日。它不是收益账本的1,525日口径。
- 非候选成员日残差仍缺失，不补入池前历史。三信号同时有效才计入覆盖率；95%阈值不变。
- 四方案在拉取数据前记入 `plan.json`：只扩池；扩池加小行业收缩；扩池加缩窗；扩池加收缩与缩窗。未依据收益或覆盖结果追加参数搜索。
- 收缩与缩窗沿用上一轮预检定义：同行少于5只时按 n/5 混合行业LOO和市场LOO；波动窗口20/最少18，动量60跳过10/最少45，趋势20跳过2/最少17。

## 数据和验证结果

- 研究期内新增股票去重194只，每日新增29—80只；OOF期间总池354—380只。
- Development最后一天2024-08-23新增73只，总池373只。这不是2026年的实时股票池。
- 194只股票的Development行情和证券状态已下载。新旧源51,698个重叠股票日的收益全部一致，最大绝对误差2.78e-16，无超过1e-6的差异。
- 登录使用指定项目已保存并验证为同账户的加密凭据；代码和实验报告不保存登录密码。

OOF三信号共同覆盖率：

- 只扩池：80.73%，不通过。原沪深300子群78.91%，新增子群88.69%。
- 扩池＋收缩：89.90%，不通过。
- 扩池＋缩窗：84.28%，不通过。
- 扩池＋收缩＋缩窗：93.41%，不通过。原沪深300子群93.42%，新增子群93.38%。五折为91.24%、95.61%、93.88%、92.16%、94.14%。

对照：原沪深300不扩池的同日预检，原始定义77.7153%，收缩＋缩窗93.1996%。本次对应80.7303%和93.4113%。后者仅提高约0.21个百分点，仍距95%约1.59个百分点。扩大分母后的总体覆盖率不能直接当成原300只股票改善的幅度，故同时披露子群。

## 为什么仍未通过

- 科技行业在OOF里“有行业、有收益但不足5个同行”的记录已降至0；剩余50,953个严格同行不足记录来自其他行业。只增加科技股不能补足其他行业的同行。
- 残差输入仍有9,828个行业缺失成员日、3,240个有行业但收益缺失成员日；本次没有用新数据擅自填补旧快照的行业缺失。
- 最佳组合中，波动信号覆盖96.40%、动量93.80%、趋势96.20%，共同覆盖93.41%。动量仍是最紧约束。
- 动量的35,075个失败成员日中，17,909个在回看50日内不足45个候选成员日；17,166个成员历史足够但有效残差不足45个。这是缺失原因审计，不是新增窗口试验。
