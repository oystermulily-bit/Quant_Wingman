# 沪深300上下文候选特征表达式

版本：`hs300_context_candidates_v1`

状态：仅供新的 Development 研究假设使用；不进入 `simple_ensemble_v1`，不改变
阶段4的 `KEEP_1D_BASELINE`，不授权启动 RD-Agent 或读取 Holdout。

## 统一符号

- `i`：目标股票；`t`：信号日。
- `U_t`：`t` 日有有效输入的沪深300成员集合。
- `G(i,t)`：`i` 在 `t` 日所属行业的有效成员集合。
- `r(i,t) = log(close_tr(i,t) / close_tr(i,t-1))`。
- `MOM20(i,t) = log(close_tr(i,t) / close_tr(i,t-20))`。
- `LOO`：Leave-One-Out，计算目标股票的同日基准时排除目标股票自身。
- `std_pop`：总体标准差，`ddof=0`。

## 表达式

### 1. 市场残差动量

```text
market_momentum_20_loo(i,t)
  = mean(MOM20(j,t), j in U_t \ {i})

market_residual_momentum_20(i,t)
  = MOM20(i,t) - market_momentum_20_loo(i,t)
```

市场基准使用等权LOO均值。目标或LOO基准缺失时输出缺失。

### 2. 行业LOO残差动量

```text
industry_momentum_20_loo(i,t)
  = mean(MOM20(j,t), j in G(i,t) \ {i})

industry_loo_residual_momentum_20(i,t)
  = MOM20(i,t) - industry_momentum_20_loo(i,t)
```

至少需要一个有效同行；行业缺失或没有有效同行时输出缺失。

### 3. 个股残差波动率

```text
stock_residual_1d(i,s)
  = r(i,s) - mean(r(j,s), j in G(i,s) \ {i})

stock_residual_volatility_20(i,t)
  = std_pop(stock_residual_1d(i,s), s=t-19,...,t)
```

要求当前成分股区间、行业区间内连续取得20个有效残差；成分股重新进入或行业
改变时重新预热。

### 4. 行业宽度

```text
industry_breadth_loo(i,t)
  = mean(1[r(j,t) > 0], j in G(i,t) \ {i})
```

分母只包含收益有效的同行，不把缺行情记录当作下跌。

### 5. 行业离散度

```text
industry_dispersion_1d_loo(i,t)
  = std_pop(r(j,t), j in G(i,t) \ {i})
```

至少需要两个有效同行，否则输出缺失。

### 6. 可交易拥挤度

```text
fully_tradable(j,t)
  = has_quote(j,t) & can_buy_open(j,t) & can_sell_open(j,t)

tradability_crowding_loo(i,t)
  = mean(1[not fully_tradable(j,t)], j in G(i,t) \ {i})
```

使用信号日当日开盘已经可知的交易状态，不读取下一交易日状态。状态证据缺失的
股票不进入分子或分母。

### 7. 指数权重变化

```text
index_weight_change_pct(i,t)
  = weight_pct(i,t) - weight_pct(i,t-1)
```

只有在 `date == entry_effective_date` 或能确认进入了新的成员区间时，前值才设为
0。若研究样本从一个既有成员区间中途开始且没有前值，则输出缺失，不把样本起点
误当作新进入。

### 8. 成分股进入时长

```text
membership_age_days(i,t)
  = calendar_days(date(t) - entry_effective_date(i,current_membership_spell))
```

这是自然日数量，不伪称交易日数量；进入日为0。进入时间缺失或晚于信号日时输出
缺失。
