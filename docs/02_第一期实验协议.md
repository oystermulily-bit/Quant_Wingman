# 第一期实验协议

本文只回答一个问题：

> 在沪深300点时成分股、A 股只做多加现金、同一预注册信号、成本、切分和组合构造下，3 日或 5 日是否相对 1 日具有稳定、可复现、扣费后仍有经济意义的 Development OOF 增量？

通过后才允许进入 `docs/03_产品待办.md`。本期结果只代表“周期可行性筛选”，不代表 RD-Agent、行业层、三层评分或最终用户白名单已经有效。
未通过则保留 1 日或简单方案，系统状态为 `KEEP_1D` 或 `MODEL_NOT_VALIDATED`，停止增加复杂度。

本文件冻结后，不得为了得到预期结论改 Holdout、成本、主指标、调仓相位或回测口径。

---

## 1. 目标与非目标

### 要做

1. 通过用户指定的行情 MCP 拉取点时正确的沪深300研究数据，并固化为不可变、本地版本化快照。
2. 在同一面板上构造 1 日、3 日、5 日毛收益标签。
3. 使用本协议预注册的三个极简个股截面信号及其等权集成，比较三个周期。
4. 主指标组合使用完整点时沪深300中的固定 Top-K 参考组合；人工白名单不承担历史主结论。
5. 3 日检查全部 3 个调仓相位，5 日检查全部 5 个调仓相位；报告全相位中位数，不准只报最好相位。
6. 使用配对时间块 Bootstrap 和预注册的多重比较控制，按主指标给出门禁结果。

### 不做

1. 不把 `000001` 或其他单票测试当 1 日基线。
2. 不使用 MT5。
3. 不跑 RD-Agent 公式搜索。
4. 不实现 FormulaValidationScorer、PortfolioDecisionScorer、完整组合优化器。
5. 不实现用户建议 API、完整网页、自动交易、前向影子盘产品化。
6. 不加入完整市场层 / 行业层模型。第一期信号只在个股截面。
7. 不做 staggered 子组合；该比较留到门禁通过之后。
8. 不使用今天人工选择的 20 只股票向历史回填并作为周期优劣证据。
9. 不访问正式 Holdout；第一期门禁只使用 Development 内部 OOF。

比较树固定为：先周期，再相位稳健性。不得回头用后面的消融改前面的周期结论。

## 2. 数据源：MCP

MCP 是研究数据的唯一上游来源，禁止 MT5。但正式训练、验证和回测不得在运行中反复调用 MCP，必须读取冻结后的本地快照。

接入前必须确认该 MCP 至少能提供：

| 能力 | 要求 |
|---|---|
| 沪深300历史成分股 | `symbol, valid_from, valid_to, known_at`；定期调样与临时调样生效日明确 |
| 日线 OHLCV | 开高低收、成交量；复权类型可区分 |
| 交易日历 | A 股交易日，含节假日 |
| 可交易状态 | 停牌、涨跌停、退市及退市处置价格；带 `available_at` |
| 数据时态 | 能区分事件发生时间、生效时间、系统可知时间 |
| 公司行动 | 分红、送转、拆并股、除权除息及公告时间，可构造可审计总回报 |

行业点时分类第一期**不是硬门槛**。MCP 若暂无行业，第一期不做行业层，不得用当前行业回填。

若 MCP 不能提供点时成分股，**停止**。不得用当前沪深300名单回填历史。

MCP 名称、接口版本、拉取时间必须写入快照清单。原始响应、标准化数据、Schema 版本、每个文件 SHA256 和整体数据指纹必须落盘；快照一经用于正式实验不得覆盖。具体选用哪一个 MCP，由用户指定后冻结。

正式数据链路固定为：

```text
MCP 拉取
→ 原始响应只读快照
→ Schema / 时态 / 完整性校验
→ 版本化 Parquet 或数据库
→ manifest + SHA256
→ 训练、验证、回测离线读取
```

## 3. 股票池与白名单

| 项目 | 第一期规定 |
|---|---|
| 分析池 | 沪深300点时成分股。当日未在池内的股票不得进入当日截面。 |
| 周期研究参考组合 | 每个调仓日按预注册集成信号在当日分析池中选择 Top 20，等权持有；这是研究代理组合，不是指数增强或最终产品建议。 |
| 人工白名单 | 第一期不作为历史主指标。仅允许测试“白名单外权重为 0”等软件约束，不输出策略有效性结论。 |
| 确定性伪白名单 | 如需白名单稳健性诊断，必须在查看结果前按固定种子和点时已知字段生成多组名单，并报告名单间分布，不能挑最好名单。 |
| 没有白名单 | 不影响第一期全池参考组合研究；产品建议阶段仍必须拒绝用户建议。 |
| 历史单票 | 忽略，不进入任何正式表 |

用户当前白名单不得用于 Development 历史周期主结论，也不得偷看 Holdout。人工白名单的可信结论留给门禁通过后的前向影子运行。全池 IC / RankIC 仍只作诊断，主指标来自上述 Top 20 参考组合。

## 4. 价格、标签、执行

### 价格

| 项目 | 推荐冻结 | 说明 |
|---|---|---|
| 特征价格 | 点时可复现的复权序列 | 复权因子、来源、版本和 `known_at` 必须保存；不得直接使用今天重新计算且会覆盖历史的前复权文件 |
| 收益与标签 | 可审计总回报开盘价 | 记为 `Open_tr`；由原始可交易价格和持有期内真实公司行动构造 |
| 涨跌停、停牌、成交判断 | 不复权或交易所公开口径 | 不得用前复权判断涨跌停 |
| 退市 | 使用退市处置价格、现金补偿或冻结的保守损失规则 | 禁止直接删除退市事件；数据不足时整个实验为 `MODEL_NOT_VALIDATED` |

### 标签（只保存毛收益）

信号在 t 日收盘后生成，t+1 开盘入场。

```text
y_1(i,t) = log(Open_tr(i,t+2) / Open_tr(i,t+1))
y_3(i,t) = log(Open_tr(i,t+4) / Open_tr(i,t+1))
y_5(i,t) = log(Open_tr(i,t+6) / Open_tr(i,t+1))
```

含义：持有 1 / 3 / 5 个交易日，到期开盘退出。第一期不允许中途退出。

交易成本和滑点不写入标签，只在组合回测按真实换手扣除。

样本必须能审计：

`signal_time, feature_available_at, entry_time, exit_time, label_end_time, tradability_known_at, label_valid, invalid_reason`

信号、预测标签和组合执行必须分开记录：

- t 日信号只由 t 日已知数据决定，生成后不得删除。
- t+1 无法成交（停牌、涨跌停、开盘缺失）时，记录 `entry_blocked=true`；组合保持现金或原持仓，不得假定成交，也不得把该组合事件从净值中删除。
- 对 IC / RankIC 等预测诊断，如果没有可审计入场价，可以令 `label_valid=false`，但必须报告无效率及其按日期、行业、状态的分布。
- 到期日无法退出时，不得删除样本；记录 `exit_delayed=true`，持有到第一个按协议可成交的时点并使用实际退出价格。
- 发生退市时使用预先冻结的退市回报规则，记录 `delisting_return`；不得通过作废负面事件提高策略表现。
- 不得用 t+1 之后才知道的状态回头删掉 t 日信号；执行失败记为执行阻塞，不改写信号。

至少保存：

`signal_generated, entry_blocked, exit_delayed, actual_exit_time, delisting_return, portfolio_pnl_included`

### 仓位映射

A 股普通模式只做多，允许现金。

禁止：`tanh(factor) ∈ [-1, +1]` 作为第一期默认仓位。
禁止：把公式值直接当成账户仓位。

第一期参考组合权重冻结为：每个调仓日在点时沪深300分析池中选取预注册集成信号 Top 20，能够成交的目标股票等权至每只 5%；因执行阻塞未使用的资金保留为现金，不临时用第 21 名替补。单股目标权重上限 5%。

IC / RankIC 必须与盈亏使用同一套标签索引，禁止再对标签做额外 +1 位移。

## 5. 交易成本（推荐冻结，待用户确认数字）

方向差异必须保留：买入无印花税，卖出有印花税。

| 项目 | 推荐默认 | 待确认 |
|---|---|---|
| 佣金（单边） | 0.00025（若有最低 5 元则在有账户资金时启用；第一期无账户资金只按比例） |  |
| 印花税 | 参考当前口径：卖出 0.0005，买入 0；历史真实成本实验按生效日期使用版本表 |  |
| 过户费 | 参考当前口径：沪深市场双边 0.00001；历史真实成本实验按生效日期使用版本表 |  |
| 滑点 | 单边 0.0005 |  |
| 冲击成本 | 第一期主实验为 0；另做总成本 ×0、×1、×1.5 敏感性 |  |
| 涨跌停 / 停牌 | 不成交，保持原权重或记执行失败 |  |
| 最低流动性 | 成交额过低则当日不可开新仓 | 门槛数字待确认 |

成本配置必须带 `cost_version, valid_from, valid_to, market, buy_rate, sell_rate, source`。正式报告同时给出统一参考成本和历史时变成本，避免把制度变化误认为周期效果。

若 5 日主要依靠低换手在净收益上胜出，而零成本下预测优势消失，应报告为“执行经济性改善”，不能写成“预测 Alpha 改善”，也不能简单称为成本假象。分别报告：

```text
gross_alpha_improvement
cost_reduction_benefit
net_strategy_improvement
```

## 6. 数据切分与 Purge

禁止机械使用“最后 10%”。`000001` 等历史单票上已查看过的尾段不得复用为沪深300正式 Holdout。

推荐日历切分（具体日期待用户确认后冻结）：

| 区间 | 推荐 |
|---|---|
| Development | 2010-01-01 至封存 Holdout 开始前一日；第一期所有周期判断只使用这里 |
| 内层训练 / 验证 | Development 内嵌套 Walk-Forward，输出严格 OOF 路径 |
| 封存 Holdout | 至少 2 个完整日历年、至少 480 个交易日，并覆盖不止一种市场状态；第一期不得读取 |
| 前向模拟盘 | 本协议不启动 |

第一期 `HORIZON_FEASIBLE_*` / `KEEP_1D` 门禁完全依据 Development OOF。正式 Holdout 留到市场/行业规则、公式集合、组合构造、成本和参考组合全部冻结后一次性运行。任何人或程序在此之前不得查看封存 Holdout 指标。

Purge 按事件区间是否重叠计算，不能只靠固定行数：

```text
训练样本的 label_end_time < 验证样本的 feature_available_at
```

若同时保留固定 bar 数，必须满足：

```text
PURGE_GAP >= max(HORIZONS) + EXECUTION_LAG_BARS
```

即至少 `5 + 1 = 6` 个交易日；推荐仍用更保守的 20 个交易日，除非数据量不足。

同一天所有股票进入同一数据区。附加未来数据不得改变历史特征。

## 7. 调仓频率与相位

预测未来 5 日不等于只能每 5 日生成一次信号。但第一期为控制多重检验，只比较：

| 周期 | 调仓 | 必须报告 |
|---|---|---|
| 1 日 | 每日调仓，持有 1 日 | 单路径 |
| 3 日 | 每 3 日调仓，持有 3 日 | 相位 0/1/2 全部 |
| 5 日 | 每 5 日调仓，持有 5 日 | 相位 0/1/2/3/4 全部 |

主结论使用**全相位中位数**。最好相位只能进附录。

每日滚动调仓、staggered 组合第一期不做。

## 8. 第一期信号注册表（冻结）

第一期只使用下列三个预注册、方向明确的简单信号。`Close_pt` 表示在 t 时点可复现的调整后收盘序列，`r_1` 表示一日对数收益：

| signal_id | 原始分数（越大越优先） | 最少历史 |
|---|---|---|
| `MOM_20` | `log(Close_pt[t] / Close_pt[t-20])` | 21 个有效交易日 |
| `REV_5` | `-log(Close_pt[t] / Close_pt[t-5])` | 6 个有效交易日 |
| `LOW_VOL_20` | `-std(r_1[t-19:t])` | 21 个有效交易日 |

为统一稳健计算，股票进入当日正式截面前还必须至少拥有 60 个连续、可审计的历史交易日；不足者当日不参与排名，不能填 0。

每个调仓日、每个信号在当日点时分析池内执行：

1. 非有限值和历史不足设为缺失，不以 0 替代。
2. 原始分数按当日截面 1% / 99% 分位截尾。
3. 转换为 `[0, 1]` 百分位排名；并列值使用平均秩。
4. 三个百分位排名简单算术平均，得到 `SIMPLE_ENSEMBLE_V1`。
5. 主指标参考组合只使用 `SIMPLE_ENSEMBLE_V1`。
6. 三个单信号结果分别进入稳健性附表；至少 2/3 单信号的周期差异方向应与集成结论一致，否则结论标记为 `INSUFFICIENT_EVIDENCE`。

禁止在看到结果后改变信号方向、窗口、截尾比例、缺失规则、组合方式或选择其中表现最好的信号作为主信号。

市场共同变量不得作为截面公式的独立输入。行业特征第一期默认关闭。

公式集成只允许上述等权方式。等权未通过前，禁止学习权重。

RD-Agent、LightGBM 边际检验、SOTA 入库第一期不启动。现有单票策略文件不参与比较。

## 9. “优于 1 日”的预注册规则

唯一主指标：

> 点时沪深300 Top 20 等权参考组合、A 股只做多加现金、按实际执行和真实换手扣费后，Development OOF 全相位中位数净夏普。

辅助门槛（必须同时满足才允许 GO）：

| 规则 | 推荐 |
|---|---|
| 相对 1 日的最低改善 | 净夏普至少高 0.15，且扣费年化至少高 2 个百分点 |
| 最大回撤 | 不差于 1 日回撤的 1.2 倍 |
| 换手 | 必须报告；若优势仅来自换手下降，需通过成本敏感性 |
| 相位稳健 | 多数相位（3 日至少 2/3，5 日至少 3/5）方向与中位数一致 |
| 最差相位 | 最差相位的净夏普不得比 1 日低 0.25 以上，且不得出现无法解释的灾难性回撤 |
| Walk-Forward | 多数折净收益方向与全样本结论一致 |
| 统计不确定性 | 对与 1 日的差值做同日期配对时间块 Bootstrap；95% 置信区间下界必须大于 0 |
| 多重比较 | 3 日对 1 日、5 日对 1 日的两个主比较使用 Holm 修正，家族显著性水平 5% |
| 成本敏感性 | 分别报告成本 ×0、×1、×1.5；区分毛 Alpha、成本节约和净策略改善，不要求零成本下必须保持同等优势 |
| 集中度 | Top 20 等权，单股目标权重 5%；行业若缺失只报告可观察集中度，不进行事后行业筛选 |

Bootstrap 默认使用 20 个交易日的移动时间块，重复至少 2,000 次，并使用固定随机种子。若样本结构不支持该设定，必须在正式运行前修改并重新冻结，不能在看过结果后调整。

失败判定：

- 未过主指标或辅助门槛 → `KEEP_1D`
- 数据无法点时对齐或协议被破坏 → `MODEL_NOT_VALIDATED`
- 3 日过、5 日不过 → `HORIZON_FEASIBLE_3D`
- 5 日过、3 日不过 → `HORIZON_FEASIBLE_5D`
- 两者都过 → `HORIZON_FEASIBLE_BOTH`
- 复杂规则尚未启用，第一期不使用 `REJECT_COMPLEXITY`

看到结果后，不得改从 Sharpe、收益、Calmar、IC 中挑最有利的一项做主结论。

全池 IC / RankIC 只诊断，不作为“优于 1 日”的证据。
