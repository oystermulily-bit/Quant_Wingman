# 第一期实验协议

本文只回答一个问题：

> 在沪深300点时成分股、用户白名单约束、A 股只做多加现金、同一成本与切分下，3 日或 5 日是否相对 1 日有稳定、可复现、扣费后仍有经济意义的样本外增量？

通过后才允许进入 `docs/03_产品待办.md`。
未通过则保留 1 日或简单方案，系统状态为 `KEEP_1D` 或 `MODEL_NOT_VALIDATED`，停止增加复杂度。

本文件冻结后，不得为了得到预期结论改 Holdout、成本、主指标、调仓相位或回测口径。

---

## 1. 目标与非目标

### 要做

1. 通过用户指定的行情 MCP 拉取点时正确的沪深300研究数据。
2. 在同一面板上构造 1 日、3 日、5 日毛收益标签。
3. 用同一套极简个股截面信号，比较三个周期。
4. 组合评估使用冻结的示例白名单；白名单外权重为 0。
5. 3 日检查全部 3 个调仓相位，5 日检查全部 5 个调仓相位；报告全相位中位数，不准只报最好相位。
6. 按预注册主指标给出门禁结果。

### 不做

1. 不把 `000001` 或其他单票测试当 1 日基线。
2. 不使用 MT5。
3. 不跑 RD-Agent 公式搜索。
4. 不实现 FormulaValidationScorer、PortfolioDecisionScorer、完整组合优化器。
5. 不实现用户建议 API、完整网页、自动交易、前向影子盘产品化。
6. 不加入完整市场层 / 行业层模型。第一期信号只在个股截面。
7. 不做 staggered 子组合；该比较留到门禁通过之后。

比较树固定为：先周期，再相位稳健性。不得回头用后面的消融改前面的周期结论。

---

## 2. 数据源：MCP

研究、验证、回测的行情与基础数据一律走用户指定的 MCP。禁止 MT5。

接入前必须确认该 MCP 至少能提供：

| 能力 | 要求 |
|---|---|
| 沪深300历史成分股 | `symbol, valid_from, valid_to, known_at`；定期调样与临时调样生效日明确 |
| 日线 OHLCV | 开高低收、成交量；复权类型可区分 |
| 交易日历 | A 股交易日，含节假日 |
| 可交易状态 | 停牌、涨跌停、退市；带 `available_at` |
| 数据时态 | 能区分事件发生时间、生效时间、系统可知时间 |

行业点时分类第一期**不是硬门槛**。MCP 若暂无行业，第一期不做行业层，不得用当前行业回填。

若 MCP 不能提供点时成分股，**停止**。不得用当前沪深300名单回填历史。

MCP 名称、接口版本、拉取时间和数据指纹必须写入每次实验记录。具体选用哪一个 MCP，由用户指定后冻结。

## 3. 股票池与白名单

| 项目 | 第一期规定 |
|---|---|
| 分析池 | 沪深300点时成分股。当日未在池内的股票不得进入当日截面。 |
| 组合可投资集合 | 冻结一份示例白名单，默认 20 只，且必须是当日点时成分股的子集。 |
| 白名单外权重 | 必须为 0 |
| 没有白名单 | 第一期直接拒绝出组合结论，不使用全池权重冒充产品建议 |
| 历史单票 | 忽略，不进入任何正式表 |

白名单用于组合主指标，不用于训练期偷看 Holdout。全池 RankIC 只作诊断，不得替代白名单组合主指标。

## 4. 价格、标签、执行

### 价格

| 项目 | 推荐冻结 | 说明 |
|---|---|---|
| 收益与标签 | 前复权开盘价 | `Open_adj` |
| 涨跌停、停牌、成交判断 | 不复权或交易所公开口径 | 不得用前复权判断涨跌停 |
| 退市 | 标签作废，`label_valid=false` | 不把退市残值写进正样本 |

### 标签（只保存毛收益）

信号在 t 日收盘后生成，t+1 开盘入场。

```text
y_1(i,t) = log(Open_adj(i,t+2) / Open_adj(i,t+1))
y_3(i,t) = log(Open_adj(i,t+4) / Open_adj(i,t+1))
y_5(i,t) = log(Open_adj(i,t+6) / Open_adj(i,t+1))
```

含义：持有 1 / 3 / 5 个交易日，到期开盘退出。第一期不允许中途退出。

交易成本和滑点不写入标签，只在组合回测按真实换手扣除。

样本必须能审计：

`signal_time, feature_available_at, entry_time, exit_time, label_end_time, tradability_known_at, label_valid, invalid_reason`

无效规则：

- t+1 无法成交（停牌、涨跌停、开盘缺失）→ 标签无效
- 持有期内连续停牌导致无法按协议退出 → 标签无效
- 不得用 t+1 之后才知道的状态回头删掉 t 日信号；执行失败记为执行阻塞，不改写信号

### 仓位映射

A 股普通模式只做多，允许现金。

禁止：`tanh(factor) ∈ [-1, +1]` 作为第一期默认仓位。
禁止：把公式值直接当成账户仓位。

第一期组合权重：在白名单内对有效多头信号做简单规范化（等权或 rank 加权，开跑前二选一并冻结），剩余为现金。

IC / RankIC 必须与盈亏使用同一套标签索引，禁止再对标签做额外 +1 位移。

## 5. 交易成本（推荐冻结，待用户确认数字）

方向差异必须保留：买入无印花税，卖出有印花税。

| 项目 | 推荐默认 | 待确认 |
|---|---|---|
| 佣金（单边） | 0.00025（万一有最低 5 元则在有资金时启用；第一期无账户资金则只按比例） |  |
| 印花税 | 卖出 0.001，买入 0 |  |
| 过户费 | 沪市双边 0.00001，深市 0 |  |
| 滑点 | 单边 0.0005 |  |
| 冲击成本 | 第一期为 0，但必须做成本 ×1.5 敏感性 |  |
| 涨跌停 / 停牌 | 不成交，保持原权重或记执行失败 |  |
| 最低流动性 | 成交额过低则当日不可开新仓 | 门槛数字待确认 |

若 5 日只在高成本口径下赢、把成本降到接近 0 后优势消失，判定为成本假象，不得写成周期 Alpha。

## 6. 数据切分与 Purge

禁止机械使用“最后 10%”。`000001` 上已用过的尾段不得复用为正式 Holdout。

推荐日历切分（具体日期待用户确认后冻结）：

| 区间 | 推荐 |
|---|---|
| Development | 2010-01-01 至 Holdout 开始前一日 |
| 内层训练 / 验证 | Development 内嵌套 Walk-Forward |
| Holdout | 最近完整日历年，至少 2 年、至少 480 个交易日 |
| 前向模拟盘 | 本协议不启动 |

Purge 按事件区间是否重叠计算，不能只靠固定行数：

```text
训练样本的 label_end_time < 验证样本的 feature_available_at
```

若同时保留固定 bar 数，必须满足：

```text
PURGE_GAP >= max(HORIZONS) + EXECUTION_LAG_BARS
```

即至少 `5 + 1 = 6` 个交易日；推荐仍用更保守的 20 个交易日，除非数据量不足。

同一天所有股票进入同一数据区。附加未来数据不得改变历史特征。

## 7. 调仓频率与相位

预测未来 5 日不等于只能每 5 日生成一次信号。但第一期为控制多重检验，只比较：

| 周期 | 调仓 | 必须报告 |
|---|---|---|
| 1 日 | 每日调仓，持有 1 日 | 单路径 |
| 3 日 | 每 3 日调仓，持有 3 日 | 相位 0/1/2 全部 |
| 5 日 | 每 5 日调仓，持有 5 日 | 相位 0/1/2/3/4 全部 |

主结论使用**全相位中位数**。最好相位只能进附录。

每日滚动调仓、staggered 组合第一期不做。

---

## 8. 第一期信号（最小）

只允许个股截面特征，例如：

- 个股过去 3 日 / 5 日收益
- 全池排名
- 个股波动率
- 个股流动性

市场共同变量不得作为截面公式的独立输入。
行业特征第一期默认关闭。

公式集成：若使用不止一个简单特征，只允许等权。等权未通过前，禁止学习权重。

RD-Agent、LightGBM 边际检验、SOTA 入库第一期不启动。现有单票策略文件不参与比较。

## 9. “优于 1 日”的预注册规则

唯一主指标：

> 示例白名单约束下，A 股只做多加现金，按真实换手扣费后，全相位中位数净夏普。

辅助门槛（必须同时满足才允许 GO）：

| 规则 | 推荐 |
|---|---|
| 相对 1 日的最低改善 | 净夏普至少高 0.15，且扣费年化至少高 2 个百分点 |
| 最大回撤 | 不差于 1 日回撤的 1.2 倍 |
| 换手 | 必须报告；若优势仅来自换手下降，需通过成本敏感性 |
| 相位稳健 | 多数相位（3 日至少 2/3，5 日至少 3/5）方向与中位数一致 |
| Walk-Forward | 多数折净收益方向与全样本结论一致 |
| 成本敏感性 | 成本 ×0 与 ×1.5 不得推翻主结论的符号；×0 下若 5 日优势消失，则判成本假象 |
| 集中度 | 单股权重上限 10%，行业若缺失则暂不约束行业 |

失败判定：

- 未过主指标或辅助门槛 → `KEEP_1D`
- 数据无法点时对齐或协议被破坏 → `MODEL_NOT_VALIDATED`
- 3 日过、5 日不过 → `GO_3D`
- 5 日过、3 日不过 → `GO_5D`
- 两者都过 → `GO_BOTH`
- 复杂规则尚未启用，第一期不使用 `REJECT_COMPLEXITY`

看到结果后，不得改从 Sharpe、收益、Calmar、IC 中挑最有利的一项做主结论。

全池 IC / RankIC 只诊断，不作为“优于 1 日”的证据。

## 10. 门禁结果与下一步

| 结果 | 允许 |
|---|---|
| `GO_3D` / `GO_5D` / `GO_BOTH` | 进入产品待办中“研究通过后才允许”的项，且只针对通过的周期 |
| `KEEP_1D` | 保留 1 日简单方案；不实现建议 API 的确定性交易含义 |
| `MODEL_NOT_VALIDATED` | 停止；等待用户决定是否改假设或换 MCP 数据 |

未通过时：不实现复杂评分器；不输出具有确定性含义的交易建议。
