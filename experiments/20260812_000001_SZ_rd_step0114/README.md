# 000001.SZ RD-Agent 第 114 轮实验快照

这是 `quant_w1ngman` 在 2026-08-12 对 `000001.SZ` 日线数据进行 RD-Agent 因子研发后的不可覆盖快照。训练目标设置为 200 轮，但本次保存点实际只完成 114 轮，因此状态是“中间快照”，不能写成已完成 200 轮。

## 训练结果

- 数据：8446 根 D1 K 线，1991-04-03 至 2026-07-29。
- 数据隔离：前 7179 根用于公式研发；最后 1267 根预留为 15% Holdout。
- 生成器：RD-Agent 风格公式提案，硅基流动 `deepseek-ai/DeepSeek-V4-Pro`；REINFORCE 未启用。
- 完成轮数：114；候选公式 1257 条，有效 1247 条，超时 0 条。
- 最优验证分数：`0.6327410340`，首次出现在第 104 轮。
- 最优公式 Token：`[36, 71, 77, 69]`。
- 最优公式：`RET_ACCEL -> SIGN -> TS_MEAN_5 -> NEG`，即 `NEG(TS_MEAN_5(SIGN(RET_ACCEL)))`。
- 训练历史中的每轮平均验证分数均值为 `-0.306699`；最后一轮平均验证分数为 `-0.502578`。这不与最优公式的 `0.632741` 冲突：前者是当轮所有候选的平均值，后者是截至该轮的历史冠军。

本次 114 轮由三段连续运行组成：1-60 轮从头训练，第 61 轮从检查点续训，第 62-114 轮再次续训。第 62 轮起公式约束从 token≤48、深度≤7、单公式≤8 秒调整为 token≤64、深度≤9、单公式≤30 秒；这一配置变化已保留在 `experiment.json` 和分段日志中。

这里的 `1.541530` 是源码通过 `np.cumsum(pnl)` 得到的累计 PnL/log-return 近似，不应直接解释成账户收益 `154.153%`。若仅作数学上的 log-return 指数换算，`exp(1.54153)-1≈367.17%`，但连续仓位与线性成本模型仍不等于真实账户复利过程。

这次回测使用全部 8446 根 K 线，其中包括训练阶段预留的最后 15%，所以它是“全历史回测”，不是严格独立的 Holdout 测试。项目原有 `strategies/holdout_000001.SZ.json` 对应另一条公式，未被纳入本实验记录。
